# The Cool Company

A boilerplate React app with a shared header (logo + nav) and a Home page.
Products and About Us are placeholder pages until built out.

## Setup

```bash
npm install
```

## Run the dev server

```bash
npm run dev
```

## Run tests

```bash
npm run test
```

## Build for production

```bash
npm run build
```

See [specs/001-homepage-boilerplate/quickstart.md](specs/001-homepage-boilerplate/quickstart.md)
for manual validation steps.
